# Boundary Test Submissions — 2-vs-3

Purpose: this is the missing comparison point. The marking prompt's
boundary-scoring instruction gives its one worked example at exactly
this boundary ("a decimal score close to the midpoint, e.g. 2.4-2.6").
Rounds 3-5 found a text-to-score gap (hedging explanation text with a
confidently non-borderline score) at the 1-vs-2, 0-vs-1 and 3-vs-4
boundaries. This round tests the boundary the worked example actually
covers, using submissions deliberately written to be genuinely
ambiguous between bands 2 and 3, matching the same construction
approach used in Round 5 (not confidently-bad, not confidently-good).
