# Boundary Test Submissions — 0-vs-1 and 3-vs-4

Purpose: the marking prompt's boundary-scoring instruction gives only
one worked example, at the 2-vs-3 boundary (2.4-2.6). Round 3/4
testing found the model can write text that clearly reasons through a
boundary case while outputting a confident, non-borderline score, at
the 1-vs-2 boundary specifically. This test checks whether the same
text-to-score gap appears at the two boundaries furthest from the
prompt's worked example (0-vs-1 and 3-vs-4), using submissions
deliberately written to be genuinely ambiguous between the two bands
(unlike the earlier confidently-Band-1 submissions), so any hedging
in the output reflects real ambiguity, not a leading question.
